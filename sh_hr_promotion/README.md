About
============
In every workplace promote to your employee is biggest factor. This module helps to manage the proper promotion process. You can manage the employee promotion flow and employee promotion history. You can print the promotion report with the promotion detail.

Installation
============
1) Copy module files to addon folder.
2) Restart odoo service (sudo service odoo-server restart).
3) Go to your odoo instance and open apps (make sure to activate debug mode).
4) click on update app list.
5) search module name and hit install button.
